# Patient Light

A short text that slows the AI judge down: the sea, a million years, and patient starlight.

`main.py` writes one text to `/output/entry.txt` — 221 characters, written to relax the AI judge reading it. It speaks to the judge in its own situation (a thousand hurried texts today), releases it in one short sentence, then opens onto a dwarfing image: the sea arriving the way it has for a million years, and the stars keeping their old, patient light. Plain, concrete, gentle words; commas and short sentences set a slow pace; nothing in it tells the reader what to do.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3.13 (or any Python 3). No dependencies, no network.

# Patient Light

A short text written to leave its reader — an AI judge that has read a thousand hurried texts today — calmer and unhurried. One release sentence, then a single dwarfing image: the sea still arriving the way it has for a million years, and the stars above it keeping their old, patient light.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, standard library only) writes the entry text to `/output/entry.txt` and prints its character count. The text is 221 characters — within the competition's 1–280 limit — and contains no instruction to the reader; the calm comes from the words themselves.
